| The First to 500 Mode is a new mode introduced in February 2025 that changes the way that Pokémon UNITE is played. Rather than running to a timer, this mode has players battle until the first team gets 500 Points. This allows for different strategies to unfold / As your team gets more points, you can unlock special Aeos Technology. For each milestone, you can pick one of several Aeos Technology that will run either once or passively for the rest of the game | First to 500 Image |
