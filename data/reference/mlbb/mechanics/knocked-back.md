# Knocked back

- For the knock-up effect, see Airborne.
> A state that prevents a target from moving, attacking, or using skills. — MLBB Skill Notes and State Guide
> The target will move away from the caster within the duration. — MLBB Skill Notes and State Guide
Knockback (v., adj. knocked back) is a form of CC that displaces an enemy by knocking them away from the caster or pushing them in the same direction that the caster is traveling. Knock Back distance ranges from barely noticeable, to very long distances, and even slightly knock enemies in the air. Independently from its strenght, Knock Back is a form of instantaneous CC that will stop enemy heroes from casting skills by very briefly stunning them, but won't usually have lasting effects.

Knocked back is considered as a blink and charge.

### Features

- Disables movement
- Disables Basic Attacks
- Disables skills
- Interrupts skills (including blink and charge; excluding skills that require channeling)
- Ignores resilience (knockback duration cannot be reduced)
- Can be prevented by control immunity

## Pulled

Pull (v.; adj. pulled) or dragged is a form of displacement CC that displaces an enemy by dragging them towards the caster or towards a designated location. It functions the same as knocked back effect, but the target will be dragged towards the attacker or to a location instead of against the target. Some forms of pulled CC effect will have a continuous effect over time while others will pull the targets only once. Most of it have an AoE effect, which can only pull one or more targets.

Like knocked back, pulled is considered as a blink/charge movement.

### Features

- Disables movement
- Disables Basic Attacks
- Disables skills
- Interrupts skills (excluding skills that require channeling)
- Ignores resilience (pulling duration cannot be reduced)
- Can be prevented by control and slowing immunity

## Abilities with only knocked back/pulled crowd control effect

Knocked back and pulled is common to be paired with other crowd control effects, like slow, stun effect or airborne. With this, it strengthens its effect.
