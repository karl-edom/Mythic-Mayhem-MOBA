# Airborne

> A state that prevents a target from moving, attacking, or using skills. The target will fly into the air within the duration.

Airborne, knocked up, knock away or knocked airborne (also written in title case) is a crowd control effect that launches the target in the air, preventing them from moving or attacking within a time duration; some of them ignore resilience and can be removed with Purify or another CC Remove abilities.

## Features

- Disables movement
- Disables Basic Attacks
- Disables skills
- Interrupts skills (including skills that require channeling)
- Some of them ignore resilience
- Can be prevented by control immunity
