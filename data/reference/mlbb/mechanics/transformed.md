# Transformed

> A state that prevents a target from attacking or using skills. The target will be transformed into other creatures. — MLBB Skill Notes

Transform (v., adj. transformed, also known as morph or morphed) is a crowd control effect that can turn a target into a harmless creature, preventing them from using basic attacks or skills. This control effect does not hinder their movement, but rather slows it down due to its association with slow.

## Features

- Reduces movement speed
- Disables basic attacks
- Disables skills
- Interrupts skills (including skills that require channeling)
- Can be reduced time controlled by resilience
- Can be prevented by control (for transformed and slowed) and slowing immunity (for slowed only)
