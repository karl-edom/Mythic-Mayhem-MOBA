# Terrified

> A state that prevents a target from attacking or using skills. The target will move randomly within the duration.

Terrified or horrified is a type of crowd control effect that causes an enemy to lose control of their character's movement and will move randomly from where they stand. Additionally, terrified targets will be unable to use Basic Attacks or skills.

## Features

- Disables movement
- Moves randomly on where they stand
- Disables Basic Attacks
- Disables skills
- Interrupts skills (excluding skills that require channeling)
- Can be reduced time controlled by resilience
- Can be prevented by control immunity

## Sources of Terrified

- Helcurt's Hidden Terror (+slowed)} (Prowler State)
- Vexana's Deathly Grasp (+knocked back)
