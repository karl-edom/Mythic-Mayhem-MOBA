# Root

> A state that prevents a target from using Blink or Charge skills.

Rooted is a crowd control effect that prevent targets from using skills that have mobility component.

Guided enhanced Basic Attacks  (e.g. Pursuit) are not disabled.

## Features

- Prevent the casting of blink/charge skills
- Ignores resilience and untargetability
- Cannot be prevented nor removed by cc immune
- Does not cancel ongoing abilities.

## Mechanics

- Root prevents you casting abilities that have Mobility tag in the description.
  - However, some abilities missing this tag, but has the mobile component (e.g. Kalea's Tsunami Slam is still disabled.

- Root prevents triggering Mobility passive, during which an error message displays on each attempt.
  - e.g. Wanwan's Tiger Pace, Ruby's Let's Dance!.

- For Benedetta's Elapsed Daytime if it is currently overcharged, the Sword Intent is set to 100 and begins depleting immediately.
  - She can still gain Sword Intent through attacking or ongoing abilities and does not affect the 4 second period of no Sword Intent gained.
  - Cannot hold basic attack button.

- Dashes that come from enhanced basic attacks, eg. Khaleed's Sand Walk, Phoveus's Demonic Force are not disabled.

- For abilities that have multiple independent components, if one component meets criteria, the ability is still disabled.
- e.g. Suyou's Evil Queller.
  - However, if the ability is uninterruptable, the current holding action is not cancelled, but release action is prohibited.
    - Evil Queller cannot be canceled once hold, but it cannot be released manually.

- A hero moving in mid air is not interrupted by Root.
  - Does not cancel Cyclone Eye's impending effect.

- Does not prohibit Teleportation abilities.
  - eg. Arrival, Luo Yi's Diversion, Moskov's Spear of Destruction.

## Battle spells disabled by roots

- Flicker is disabled by root.
  - However Sprint and Arrival are not.

## List of abilities disabled by roots without Mobility tag

| Hero | Ability |
| --- | --- |
| Suyou | Evil Queller |
| Angela | Heartguard |
| Hanzo | Forbidden Ninjutsu Soul Snatch |

## Counter

- Since root comes with slow, it is advised to equip with Purify to avoid stun and Sprint to move out of the area.

## Sources of Rooted

- Minsitthar's King's Calling (+slowed)
- Obsidia's Hunt of Bone (+stunned)

## Trivia

- Minsitthar was the only hero who can apply this crowd control effect until Obsidia released.
- To check which abilities of your hero are disabled by Root, in Hero Training mode, you can summon one or two ally Layla around enemy Minsitthar, the computer will cast King's Calling.
