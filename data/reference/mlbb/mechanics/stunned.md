# Stunned

- Not to be confused with S.T.U.N. skin series.
> A state that prevents a target from moving, attacking, or using skills. — MLBB Skill Notes and State Guide
Stunned or stun effect is a type of crowd control effect that prevents a target to move, use their basic attack or use skills. Stun effect can last from at least 1 second, up to 2 whole seconds.

## Features

- Disables movement
- Disables Basic Attacks
- Disables skills
- Interrupts skills (excluding skills that require channeling)
- Can be reduced time controlled by resilience
- Can be prevented by control immunity

## Advanced stun effects

Not to be confused with Winter Crown's Unique Passive, Frozen

### Frozen

Frozen or freeze is one of the advanced stun effects. It has same to stun effect, but it will interrupt channeling skills.

For non-player controlled units, such as Turrets, they reset the stacking damage and reselect valid target to attack.

#### Features

- Disables movement
- Disables Basic Attacks
- Disables skills
- Interrupts skills (including skills that require channeling)
- Can be reduced time controlled by resilience
- Can be prevented by control immunity
- Freeze current animation

#### Sources of Frozen

- Atlas' Frigid Breath
- Aurora's Pride of Ice, Frosty Breeze & Frigid Glacier (+slowed)

### Suppressed

> This is an advanced stunning effect that interrupts all skills, ignores resilience, and can’t be removed. — MLBB Skill Notes and State Guide
Suppressed or suppression is one of the advanced stun effects, and considered as the most powerful stun effect, even the most powerful CC effect. It has the same stun effect features, but it will now ignore resilience and it cannot be removed by Purify or any remove CC abilities.

#### Features

- Disables movement
- Disables Basic Attacks
- Disables skills
- Interrupts skills (including skills that require channeling)
- Ignores resilience, control immunity

#### Sources of Suppressed

##### Hero abilities
