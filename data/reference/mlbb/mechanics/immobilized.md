# Immobilized

- Not to be confused with rooted, another crowd control effect.

> A state that prevents a target from moving. The target can't use Blink within the duration.

Immobilized is a type of crowd control effect that prevents the enemy from moving, locking them in place. It does not prevent them from using Basic Attack or skills except for most Blink/Charge skills.

## Features

- Disables movement
- Disables Basic Attacks
- Disables blink/charge skills
- Can be reduced time controlled by resilience
- Can be prevented by control immunity
