# Healing effect

> Healing Effect determines the strength of a hero's HP Regen and Shield effects. — Support Emblem's Healing Effect description

Healing effect is an attribute that modifies the final heal and shield's value to the recipient. The default healing effect is 100% (0% when displayed on hero stats in-game.)

Unlike healing received, this can also increase or decrease the value of healing and shields given to the recipient's allies, but not increase or decrease the aforementioned values from external sources.

Healing effect can be increased or decreased multiplicatively by using items, battle spells, and hero abilities, however it can also be decreased to a negative percentage to reduce the heal and shield instead (this is theoretically impossible).

## Notes

## Increasing healing effect

### Emblem

- Support Emblem (12%, level 60)

### Equipment

- Flask of the Oasis (12%)

## Decreasing healing effect

- In Brawl Mode, support heroes that heal allies have varied decrease in healing effect for game balancing purposes.

## Calculation

> Healing Effect — MLBB hero skill notesWhen the healing received attribute is present alongside healing effect, they will be simply added.

${\rm actual\ value} = original\ value + (total\ healing\ effect% + total\ healing\ received%)$
