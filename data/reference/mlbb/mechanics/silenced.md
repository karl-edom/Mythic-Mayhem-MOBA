# Silenced

> A state that prevents a target from using follow-up skills. Skills that have already been used but yet to be effective won't be affected.

Silenced is a form of crowd control effect that prevents the target from using skills, without hindering Movement or Basic Attacks.

## Features

- Disables skills
- Interrupts skills (excluding skills that require channeling)
- Ignores resilience
- Can be prevented by control immunity
